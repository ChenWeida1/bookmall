# 纸间书店 UI 原型（墨刀）

导入墨刀时使用 `docs/prototype/color/` 下的彩色效果图。同目录上一级的 PNG 是白底灰线的线框，只作对照，不要再导入。需求只来自《需求规格说明书》V1.1。第一版结算全部购物车。游客只能浏览图书列表和详情；加入购物车、购物车、下单、订单、通知必须登录。

彩色稿为暖纸色背景、墨绿顶栏，价格为朱色。画布按 **16:9** 桌面页导入。图中的书名、订单号、金额是示意数据，用来把字段摆出来，不是种子数据清单。

本原型不包含：真实支付、物流、收货地址、优惠券、积分、会员、秒杀、评价、管理后台、搜索引擎、推荐。

## 1. 导入墨刀

1. 打开 <https://modao.cc> 并登录，新建项目，类型选 **原型**，设备选桌面。画布选 **16:9**（彩色稿按这个比例出图）。
2. 在左侧页面列表新建 9 个页面，页面名使用下表「墨刀页面名」。
3. 进入对应页面，把 `color/` 里的 JPG **拖入画布**，或使用「插入 → 图片」上传。选中图片，放到左上角，铺满画布。
4. 右键图片，选择 **锁定**（有「设为背景」时优先设为页面背景），避免后面画热区时把底图拖走。
5. 从组件里拖出 **热区**（有的版本叫「链接区域」），盖住按钮、导航和表格链接。选中热区，在右侧交互里设置：**单击 → 跳转到页面**，目标用下表。
6. 右上角预览，按第 4 节演示脚本点一遍。

若当前账号的页面列表支持「导入图片 / 从图片新建」，可一次选中 `color/` 里的 9 张 JPG，让每张图变成一页，再按第 4–5 步补热区。没有该入口时，用上面的拖入画布方式即可。图片是整页底图，不要再在图上重画一套按钮。

## 2. 页面清单

| 墨刀页面名 | 彩色文件                             | 谁能看    | 图上画了什么                                       |
| ----- | -------------------------------- | ------ | -------------------------------------------- |
| 书城    | `color/home-color.jpg`           | 游客、读者  | 分类筛选、书名关键字（P1）、8 本图书卡片、分页                    |
| 图书详情  | `color/book-detail-color.jpg`    | 游客、读者  | 《围城》的封面、书名、作者、分类、价格、库存、ISBN、上架状态、简介、数量、加入购物车 |
| 登录    | `color/login-color.jpg`          | 游客主动进入 | 用户名、密码、登录；链到注册                               |
| 注册    | `color/register-color.jpg`       | 游客     | 用户名、密码、昵称（可选）、注册；链到登录                        |
| 购物车   | `color/cart-color.jpg`           | 读者     | 两条条目的封面、书名、单价、数量、小计、删除；合计与提交订单               |
| 我的订单  | `color/orders-color.jpg`         | 读者     | 订单号、总金额、状态「已创建」、创建时间、商品件数                 |
| 订单详情  | `color/order-detail-color.jpg`   | 读者     | 订单头与明细（书名、单价、数量、小计）                          |
| 消息中心  | `color/notifications-color.jpg`  | 读者     | 通知标题、内容、未读/已读、时间；标记已读与全部已读（P1）               |
| 请先登录  | `color/login-required-color.jpg` | 游客被拦截时 | 与登录页同一套表单，并写明购物车、订单、消息需要登录                   |

顶栏有两种状态，不要做成两个产品：

- 游客（书城、图书详情、登录、注册、请先登录）：右侧是「登录」「注册」。
- 读者（购物车、我的订单、订单详情、消息中心）：右侧是昵称「纸间读者」和「退出」。

登录或注册成功后，书城仍是 `color/home-color.jpg` 这一张图。演示时在口头说明右上角改为昵称和退出；若要在墨刀里看见登录后的顶栏，复制「书城」页，只改右上角两个字，不要加新功能。

## 3. 热区

公共顶栏（每一页都有）：

| 热区      | 游客点击       | 读者点击                      |
| ------- | ---------- | ------------------------- |
| 纸间书店、书城 | 书城         | 书城                        |
| 购物车     | 请先登录       | 购物车                       |
| 我的订单    | 请先登录       | 我的订单                      |
| 消息      | 请先登录       | 消息中心                      |
| 登录      | 登录         | （读者顶栏没有此项）                |
| 注册      | 注册         | （读者顶栏没有此项）                |
| 退出      | （游客顶栏没有此项） | 书城。退出后购物车、订单、消息再次进入「请先登录」 |

「请先登录」在原型里只画了一张。墨刀的一个按钮只能链到一个目标页。演示主路径时，让这页的「登录」跳到 **购物车**（对应验收脚本：退出后再进购物车会被要求登录）。若要区分来源，把该页复制三份，登录成功分别回到购物车、我的订单、消息中心；从详情未登录加购过来的，登录成功回到图书详情。

| 登录、注册          | 登录、注册                                  |

卡片字段：书名、作者、封面、价格、库存、分类名。

### 图书详情 `book-detail.png`

| 元素                | 点击后                                |
| ----------------- | ---------------------------------- |
| 面包屑「书城」           | 书城                                 |
| 数量减、加             | 留在本页。默认 1，必须是正整数                   |
| 加入购物车（图上是游客顶栏）    | 请先登录                               |
| 加入购物车（读者，见上文顶栏说明） | 留在本页，提示「已加入购物车」。同一用户同一本书合并数量，不新增一行 |

详情在列表字段之外还有：简介、ISBN（可选）、上架状态。图上为「在售（ON_SALE）」。下架（OFF_SALE）不可加入购物车，提示「该图书暂不可购买」。

### 登录 `login.png`

| 元素       | 点击后                        |
| -------- | -------------------------- |
| 登录       | 校验通过后到书城，并视为已登录（顶栏改为昵称和退出） |
| 没有账号？去注册 | 注册                         |

字段只有用户名、密码。没有手机、验证码、第三方登录。

### 注册 `register.png`

| 元素       | 点击后         |
| -------- | ----------- |
| 注册       | 成功后自动登录，到书城 |
| 已有账号？去登录 | 登录          |

字段：用户名（3–20 个字符，唯一）、密码（6–32 个字符）、昵称（可选，留空则等于用户名）。

### 购物车 `cart.png`

| 元素    | 点击后                                                  |
| ----- | ---------------------------------------------------- |
| 数量减、加 | 留在本页，重算小计和合计。数量改为 0 等于删除该行                           |
| 删除    | 留在本页，去掉该行并重算合计                                       |
| 提交订单  | 成功后到订单详情（示意订单 `20261009120000A8K2`），并应能再到消息中心看到一条新通知 |

图上写明「第一版结算全部购物车，不支持勾选」。没有收货地址、优惠券、支付方式。示意内容：围城 ×2 = ¥79.60，计算机系统 ×1 = ¥139.00，合计 ¥218.60，商品件数 3。

### 我的订单 `orders.png`

| 元素        | 点击后                                              |
| --------- | ------------------------------------------------ |
| 第一行「查看详情」 | 订单详情                                             |
| 第二行「查看详情」 | 原型只画了第一笔订单的详情。墨刀里可先链到同一张订单详情，或复制一页改成 ¥68.00、件数 1 |

列表按创建时间倒序。界面上的状态写「已创建」（对应接口状态 `CREATED`，无需支付）。不画取消、支付、物流。

### 订单详情 `order-detail.png`

| 元素               | 点击后  |
| ---------------- | ---- |
| 返回订单列表、面包屑「我的订单」 | 我的订单 |

订单头：订单号、状态 CREATED、创建时间、总金额、商品件数。明细：书名、单价、数量、小计。只能看本人订单。

### 消息中心 `notifications.png`

| 元素        | 点击后                        |
| --------- | -------------------------- |
| 标记已读      | 留在本页，该条从未读变为已读。这是 P1       |
| 全部已读      | 留在本页，全部变为已读。这是 P1，图上标了「可选」 |
| 通知正文中的订单号 | 可链到订单详情。不作为必须热区            |

字段：标题、内容、是否已读、时间。未读用灰底和圆点区分。内容句式：`您的订单 {订单号} 已创建成功，合计 ¥{金额}`。

### 请先登录 `login-required.png`

这是未登录访问受保护页时的登录引导，**不与 `login.png` 合并**，这样墨刀可以把「主动登录」和「被拦截后登录」分成两个跳转。表单仍是用户名、密码。

| 元素       | 点击后                                     |
| -------- | --------------------------------------- |
| 登录       | 演示主路径回到购物车。复制页面后可分别回到购物车、我的订单、消息中心或图书详情 |
| 没有账号？去注册 | 注册                                      |
| 顶栏「注册」   | 注册                                      |

会进入本页的操作：游客点击顶栏购物车、我的订单、消息；游客在详情点击加入购物车；Token 缺失或过期（401）。

## 4. 建议演示顺序

1. 书城看列表，点进图书详情。
2. 详情点「加入购物车」，进入请先登录。
3. 去注册，成功后回到书城（此时视为已登录）。
4. 再进详情加入 2 本，打开购物车核对数量与合计。
5. 提交订单，进入订单详情；打开我的订单能看到同一笔；打开消息中心能看到下单成功通知。
6. 退出后点购物车，再次进入请先登录。

## 5. 空态

线框画的是有数据的主路径。墨刀里用热区旁的说明，或复制页面后只改中间文案，不要加新模块。

| 页面             | 空态文案     | 出口                           |
| -------------- | -------- | ---------------------------- |
| 书城（分类或关键字没有结果） | 没有找到相关图书 | 点「全部」回到有书的列表                 |
| 购物车            | 购物车是空的   | 「去书城看看」到书城。此时没有「提交订单」，或按钮不可用 |
| 我的订单           | 还没有订单    | 「去书城看看」到书城                   |
| 消息中心           | 暂无消息     | 无跳转                          |
| 图书详情（图书不存在）    | 图书不存在    | 「返回书城」                       |

## 6. 错误提示

接口失败时用可读中文，不展示堆栈。原型不另画错误页，用页面内一行提示即可。

| 场景          | 提示                           | 出现位置         | 之后                                          |
| ----------- | ---------------------------- | ------------ | ------------------------------------------- |
| 用户名已存在      | 用户名已存在                       | 注册           | 留在注册                                        |
| 用户名或密码不符合长度 | 用户名需为 3–20 个字符；密码需为 6–32 个字符 | 注册           | 留在注册                                        |
| 用户名或密码错误    | 用户名或密码错误                     | 登录、请先登录      | 留在当前页。不要提示具体是用户名错还是密码错                      |
| 未登录或登录已失效   | 请先登录                         | 加购、购物车、订单、消息 | 到请先登录                                       |
| 数量不是正整数     | 数量必须为正整数                     | 详情、购物车       | 留在当前页                                       |
| 图书不存在       | 图书不存在                        | 详情、加购        | 可回书城                                        |
| 图书不可售       | 该图书暂不可购买                     | 详情加购         | 留在详情                                        |
| 购物车为空仍提交    | 购物车是空的，无法提交订单                | 购物车          | 留在购物车，不产生订单                                 |
| 库存不足        | 库存不足，订单未创建                   | 提交订单         | 整单失败，不产生订单，库存不变。至少说明失败原因；能具体到书更好，例如「围城库存不足」 |
| 查看他人订单      | 订单不存在或无权查看                   | 订单详情         | 不泄露该订单是否存在                                  |

加购时建议校验库存；第一版要求在 **提交订单** 时做强校验。库存不足不得把库存扣成负数，也不得出现「库存已扣但没有订单」。

通知若暂时创建失败，订单仍然成功（P1 可接受）。消息中心当时可以没有这条，不把下单说成失败。
